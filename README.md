# זיכרון ארגוני — Organizational Memory POC

אפליקציית POC מקומית לצבירת ידע עסקי לאורך זמן מתוך מקורות מידע שונים (פגישות, מיילים, מסמכים, קבצי אקסל וכו'),
ארגון הידע בנושאים עם ציר זמן, תיוג, וניתוח AI (Claude) שמזהה עובדות, החלטות, השערות, שאלות פתוחות וקשרים
בין מקורות — כולל בין נושאים שונים.

## ארכיטקטורה

- **Backend**: Python (FastAPI) + SQLite. אחראי על ניהול הנתונים, חילוץ טקסט מקבצים שמועלים (PDF/Word/Excel/CSV),
  ותקשורת עם Claude API. כל הלוגיקה מול Claude מבודדת בקובץ אחד (`app/services/claude_service.py`) כדי שיהיה קל
  להחליף/להרחיב בעתיד.
- **Frontend**: React (Vite), ממשק בעברית מלאה (RTL), ללא ספריית UI חיצונית — CSS פשוט ונקי.
- **אחסון**: קובץ SQLite מקומי יחיד (`backend/data/app.db`), קבצים שהועלו נשמרים ב-`backend/uploads/`.
- **AI**: Claude API (Anthropic), נקרא רק מצד השרת. המפתח נטען ממשתנה סביבה ולעולם לא נחשף לפרונטאנד.

אין אימות משתמשים, אין רב-משתמשים, אין פריסה לענן — הכול רץ מקומית, כמתוכנן ל-POC.

## הרצה

### דרישות מוקדמות
- Python 3.11+ (מ-python.org, לא Microsoft Store)
- Node.js 18+ (כבר מותקן)
- מפתח API של Anthropic (מ-console.anthropic.com)

### 1. הגדרת השרת (Backend)

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

לאחר מכן ערכו את `backend/.env` והדביקו את מפתח ה-API שלכם:

```
ANTHROPIC_API_KEY=sk-ant-...
```

הרצת השרת:

```bash
cd backend
.venv\Scripts\activate
uvicorn app.main:app --reload --port 8000
```

השרת יעלה בכתובת http://localhost:8000 (תיעוד API אוטומטי זמין ב-http://localhost:8000/docs).

### 2. הרצת הממשק (Frontend)

בטרמינל נפרד:

```bash
cd frontend
npm install
npm run dev
```

הממשק יעלה בכתובת http://localhost:5173 — פתחו אותה בדפדפן.

## מה בנוי (MVP)

- ניהול נושאים (יצירה, עריכה, מחיקה, חיפוש)
- הוספת מקורות מידע לכל נושא: הדבקת טקסט חופשי או העלאת קובץ (PDF/Word/Excel/CSV/טקסט) עם חילוץ טקסט אוטומטי
- ציר זמן כרונולוגי לכל נושא, עם תגיות, תיאור, ותצוגת/הסתרת תוכן מלא
- תיוג ידני (הוספה/הסרה) ותיוג אוטומטי ע"י AI (מסומן בנפרד ויזואלית)
- מסך תגיות: כל התגיות בנושא, עם אפשרות ללחוץ ולראות את כל המקורות עם תגית זו — **כולל מנושאים אחרים**
- ניתוח AI אוטומטי בעת הוספת מקור: הצעת תגיות, זיהוי עובדות/החלטות/השערות/שאלות פתוחות/משימות, וזיהוי קשרים
  אפשריים למקורות אחרים (גם חוצי-נושאים), עם תיוג ברור כ"קשר אפשרי" ולא כעובדה
- מסך "תובנות AI" לכל נושא: ריכוז כל התובנות שנאספו מכל המקורות, מקובצות לפי סוג, עם ציון המקור לכל פריט
- מסך "שאל את ה-AI": שאלות חופשיות על הנושא (כולל 9 שאלות לדוגמה מוכנות ללחיצה), עם תשובה שמבחינה בין עובדות,
  החלטות, השערות, שאלות פתוחות, הסקות AI וקשרים אפשריים, ומתייחסת גם למקורות רלוונטיים מנושאים אחרים
  (על בסיס תגיות משותפות)

## מה עוד לא מומש / הרחבות אפשריות

- דמיון סמנטי אמיתי (embeddings/וקטורים) לזיהוי קשרים — כרגע הזיהוי מבוסס על תגיות משותפות + הבנת Claude את
  התוכן המלא בזמן הניתוח, לא על חיפוש וקטורי. לעומק רב יותר, אפשר להוסיף מסד וקטורים (למשל Chroma/FAISS)
- "מה השתנה מאז הפגישה הקודמת" נענה ע"י Claude מתוך כלל ציר הזמן בכל קריאה, ולא ע"י מנגנון diff ייעודי
- אין עריכת/מחיקת נושאים ומקורות מתוך מסך "תובנות" (רק מהטיימליין)
- אין absolute אימות משתמשים / הרשאות — כמתוכנן, זה POC אישי
- אינטגרציית Teams/Outlook — לא בתכנון לשלב זה

## הדגמה מומלצת (הזרימה המרשימה ביותר)

1. צרו שני נושאים: **Recovery** ו-**מדיניות אשראי**
2. הוסיפו ל-Recovery מקור ראשון (למשל "פגישה עם משפטית") עם תוכן טקסט חופשי שמזכיר "איכות תיק האשראי"
   ותייגו/תנו ל-AI להציע תגית כמו "איכות תיק"
3. הוסיפו ל-מדיניות אשראי מקור עם תוכן שמזכיר גם הוא "איכות תיק האשראי"
4. עברו למסך "תובנות AI" או "תגיות" בנושא Recovery ולחצו על התגית המשותפת — תראו את המקור מהנושא האחר
5. עברו למסך "שאל את ה-AI" ולחצו על השאלה "אילו מקורות מנושאים אחרים עשויים להיות רלוונטיים?" — Claude יזהה
   את הקשר החוצה-נושאים ויסמן אותו כ"קשר אפשרי", עם הפניה למקורות הרלוונטיים
6. הוסיפו עוד 2-3 מקורות לאורך זמן (תאריכים שונים) לאותו נושא, ואז שאלו "מה השתנה מאז הפגישה הקודמת?" ו"תכין
   אותי לפגישה הבאה" כדי להראות את יכולת הסינתזה על פני ציר הזמן
